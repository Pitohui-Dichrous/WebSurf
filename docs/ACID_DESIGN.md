# WebSurf — 酸性设计

分支：`酸性设计`。基线：WebSurf 0.5.0，`5a4b05a`。

## 设计方向

WS.png 是应用标识的唯一图像源。保留原图的完整方形构图、色彩和像素内容，不重新描画星球，不添加单色滤镜。界面延续图中的黑色、白色与荧光绿，通过字体尺度、硬边色块、细线和不对称排版形成层次。

参考 [Kurppa Hosk 的 Marathon / Bungie 项目](https://www.kurppahosk.com/work/bungie) 与 [Marathon 官方页面](https://marathonthegame.com/) 的粗窄文字、强色面及精细功能标记。只提取构图原则，不使用其商标、游戏图像或阵营图案。

- 展示文字和进度百分比：Barlow Condensed ExtraBold；中文操作：系统无衬线；速度与体积：等宽数字。
- 资源页面：缩略图确认内容，分辨率提供主要识别信息，格式和时长作为次级信息。
- 资源状态使用用户提供的音频、文档和未知文件图案；读取预览时使用原始动态 GIF。完整保留颜色与方形构图，SVG 静态资源机械渲染后供原生界面显示；原文件、许可和哈希随源码保留。
- 下载页面：进度与传输状态形成视觉重点，保留完整错误、重试、取消、打开和边下边播。
- 浏览器：工具栏维持易触达的尺寸，网页内容保留原站设计，视频下方的接管入口与原生界面统一。
- 视频画面上的接管播放器沿用 0.5.0 的白色透明悬浮控件与渐隐阴影，不添加荧光绿按钮底色或上下实体色块。酸性设计用于视频画面以外的应用界面。
- 明暗主题使用不同的主色面与按钮颜色关系，灰阶表面不叠绿色蒙层。
- 动作图标沿用项目内具有来源及许可的 Lucide 矢量图。

## 行为边界

这次修改重构界面，不替换 Chromium WebView、下载队列、并发引擎、HLS 合并、共享媒体缓存或视频跟随机制。打开面板、切换应用主题不应刷新网页。资源筛选、完整错误、下载状态反馈及后台通知仍需可用。

下载命名另修复了 `remote_control.php` 等接口名抢占视频标题的问题。真实响应文件名优先；播放器占位名回退到视频或所属标签页标题。HLS 使用入口清单的命名信息，输出保持 MP4；已有文件不会自动改名。

预览取帧优先第 3 秒，短视频使用首帧；保留网页封面和 HLS 的现有预览边界。原生播放缓存避开片头 3 秒，不改变视频播放位置。加载动画跟随资源行的可见性启停，并尊重系统关闭动画的设置。

## 验证入口

`AcidDesignTest` 提供原生界面的定向检查与截图：

- 浅色、深色下浏览器工具栏、菜单、设置及设置滚动区域。
- 资源缩略图与清晰度、音频筛选。
- 下载进行中、完成和错误记录；错误操作可滚动到屏幕中。
- 打开面板与切换主题后，保持原 WebView 和页面 epoch。
- 在真实软键盘出现时编辑并保存主页；通过并发选择页实际切换 8 / 16 路并确认设置保留。
- 标签页数字与图标前方方框共用坐标：检查浅深主题下 1 / 8 / 12 的排版和数字中心的真实点击。12 仅为排版样本，标签页数量上限仍为 8。

测试截图使用本地合成资源和明确设置的下载状态，不代表真实公网视频的下载测速。截图写入应用外部文件目录 `qa/acid-*.png`。可传入 `acid_capture_prefix` 区分普通尺寸与窄屏截图。

补充复用 `ProductLayoutTest` 检查 320dp、1.3 倍字体的长中文和完整错误；`ThemeResourceUiTest` 检查网页接管按钮的位置与对比度；`VideoControlsTest`、`ScrollPlaybackTest` 检查原生播放操作与滚动关系。发布检查结果见 [验证摘要](release-verification.json)。
