# WebSurf

<img src="app/src/main/res/drawable-nodpi/ws_logo.png" width="160" alt="WebSurf">

100% vibe coding + REA

主要用于下载网页中视频并嗅探网页资源。

本体为 Chrome（Chromium WebView）内核浏览器，可以方便接管网页内视频播放并下载。

使用特殊播放器的网页不可以，油管别想啦

## 基本功能

- 网页视频原位播放、全屏和小窗，随时切回网页，无需刷新。
- 嗅探视频、音频、图片等资源，提供视频缩略图和清晰度。
- 支持普通视频与 m3u8 下载，下载后合并为 MP4。
- 支持多路下载、边下边播、下载管理和浅色/深色外观。
- 可切换搜索引擎，默认必应国内版。

Android 8.0 及以上。默认百度首页，可在设置中修改。
